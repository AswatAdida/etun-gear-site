Политика обработки персональных данных

Дата публикации: 22 ноября 2026 года

1. Общие положения

Настоящая Политика определяет порядок обработки персональных данных посетителей сайта «Ётун», расположенного по адресу https://aswatadida.github.io/etun-gear-site/.

Оператор персональных данных — Мацко Анастасия Алексеевна, физическое лицо, применяющее специальный налоговый режим «Налог на профессиональный доход».

Контактный адрес для обращений по вопросам обработки персональных данных: aswatadida@gmail.com.

2. Какие данные обрабатываются

При оформлении заявки на заказ могут обрабатываться следующие сведения:

  • имя покупателя;
  • номер телефона и/или адрес электронной почты;
  • сведения, необходимые для организации доставки, если они запрашиваются в форме;
  • состав заказа, количество товаров и сумма заказа;
  • иные сведения, которые покупатель добровольно сообщает при оформлении заявки.

3. Цели обработки

Персональные данные обрабатываются для получения и рассмотрения заявок, связи с покупателями, согласования заказа, оплаты и доставки товаров, а также выполнения применимых законодательных обязанностей.

Отправка рекламных сообщений не осуществляется на основании одного лишь согласия на обработку данных для заказа. При необходимости рекламной рассылки запрашивается отдельное согласие.

4. Порядок обработки и используемые сервисы

Для получения заявок используется сервис QForm, предоставляемый ООО «КУФОРМ». В соответствии с условиями выбранной лицензии Personal Data Free владелец формы и ООО «КУФОРМ» указаны в согласии в качестве операторов персональных данных.

При обработке данных могут осуществляться сбор, запись, хранение, использование, уточнение, передача, удаление и иные действия, необходимые для указанных целей.

Сведения о заказах могут поступать оператору по электронной почте. Доступ к ним должен быть ограничен лицами, участвующими в обработке заявок.

5. Сроки хранения

Согласно условиям выбранной лицензии QForm Personal Data Free, срок хранения данных в сервисе составляет один год.

Данные, полученные оператором за пределами QForm, хранятся не дольше, чем необходимо для соответствующей цели обработки, если иной срок не установлен законодательством.

6. Права субъектов персональных данных

Пользователь вправе обращаться за информацией об обработке своих персональных данных, требовать их уточнения, блокирования или удаления при наличии предусмотренных законом оснований, а также отзывать согласие на обработку.

Для обращения к оператору сайта используется адрес aswatadida@gmail.com.

Отзыв согласия не всегда означает немедленное удаление всех сведений, если законодательство предусматривает иные основания или обязанности по их хранению.

7. Защита персональных данных

Оператор принимает необходимые организационные и технические меры для защиты персональных данных от неправомерного доступа, изменения, распространения и иных неправомерных действий.

8. Изменение политики

Политика может обновляться при изменении способов обработки персональных данных, используемых сервисов или применимых требований законодательства.

Актуальная версия публикуется по адресу https://aswatadida.github.io/etun-gear-site/privacy.html.
