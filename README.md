# Ётун — сайт бренда

Статический адаптивный сайт на HTML, CSS и обычном JavaScript. Для локального запуска нужен только Python 3. Яндекс Метрика загружается при наличии доступа к сервису.

## Локальный просмотр

Из папки, где находится `index.html`:

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000/. Проверьте логотип, четыре карточки каталога и переходы к разделам «Каталог», «Материал», «Доставка» и «О бренде». Favicon доступен по адресу http://localhost:8000/favicon.png.

## Корзина

Цены и единицы продажи заданы в `cart.js`. В `localStorage` под ключом `etun_cart_v1` хранятся только ID товаров и их количества. Для товара, который продаётся парой, количество 1 означает одну пару.

Для проверки добавьте две пары защиты для ледовых инструментов, одну защиту для ледоруба, три колпачка для ледобуров и одну пару чехлов для кошек. Корзина должна показать 3 000 ₽ без доставки и восстановиться после перезагрузки страницы.

## Публикация

Загрузите содержимое этой папки в корень публичного репозитория GitHub и включите GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Оформление заказа через QForm

Используется существующая форма «Ётун — оформление заказа» (форма 36677, пространство 58644). При оформлении с непустой корзиной скрипт QForm загружается на страницу. Сайт заполняет скрытые поля `order_items` и `order_total` из каталога. Итог передаётся в рублях числом без доставки. Контакты покупатель вводит в QForm. Они не попадают в URL или localStorage сайта. Сумму и состав заявки продавец подтверждает вручную.

Перед включением отправки:

1. Проверьте домен `aswatadida.github.io` в настройках пространства. В форме проверьте обязательные поля контактов, доставки и согласия, необязательный комментарий, а также активные скрытые поля `order_items` и `order_total`. Утвердите политику в `privacy.html` и условия обработки данных.
2. В настройках JavaScript-событий существующей формы добавьте обработчик **после успешной отправки**.

   ```js
   window.dispatchEvent(new CustomEvent('etun:qform-success'));
   ```

3. Для проверки на разрешённом домене включите `orderSubmissionEnabled` в `checkout-config.js`. Отправьте согласованную заявку с синтетическими данными. В кабинете проверьте оба скрытых поля и уведомление на настроенном адресе. Убедитесь, что обработчик QForm срабатывает в том же окне и корзина очищается только после приёма заявки. Если событие не доходит до страницы, оставьте отправку выключенной до выяснения причины.

Документация QForm по [скрытым полям](https://qform.blog/develop/hidden_field) и [JavaScript-событиям](https://qform.blog/develop/javascript_events).
