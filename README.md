# Ётун — сайт бренда

Статический адаптивный сайт: HTML + CSS. Без сборки и зависимостей.

## Локальный просмотр

Из папки, где находится `index.html`:

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000/

## Публикация

Загрузите содержимое этой папки в корень публичного репозитория GitHub и включите GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Изображения

Пять изображений предоставлены владельцем проекта и хранятся в `assets/` в оптимизированном формате WebP.

## SEO

Основной поисковый запрос: «защитные чехлы для ледорубов». После публикации подтвердите сайт в Яндекс.Вебмастере и отправьте главную страницу на переобход.

## Примечание

Фирменная эмблема использована из предоставленного изображения; заголовки набраны близким по характеру жирным геометричным шрифтом, так как отдельный файл фирменного шрифта не предоставлен.
