# Ётун — сайт бренда

Статический адаптивный сайт на HTML, CSS и обычном JavaScript. Для локального запуска нужен только Python 3. Яндекс Метрика загружается при наличии доступа к сервису.

## Локальный просмотр

Из папки, где находится `index.html`:

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000/. Проверьте логотип, четыре карточки каталога и переходы к разделам «Каталог», «Материал», «Доставка» и «О бренде». Favicon доступен по адресу http://localhost:8000/favicon.svg.

## Корзина

Цены и единицы продажи заданы в `cart.js`. В `localStorage` под ключом `etun_cart_v1` хранятся только ID товаров и их количества. Для товара, который продаётся парой, количество 1 означает одну пару.

Для проверки добавьте две пары защиты для ледовых инструментов, одну защиту для ледоруба, три колпачка для ледобуров и одну пару чехлов для кошек. Корзина должна показать 3 000 ₽ без доставки и восстановиться после перезагрузки страницы.

## Публикация

Загрузите содержимое этой папки в корень публичного репозитория GitHub и включите GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Оформление заказа

Сводка и отправка используют одну корзину и цены из каталога. Персональные данные из формы остаются в памяти вкладки до отправки, закрытия страницы или перезагрузки. В localStorage они не записываются. Письмо рассматривается как заявка для ручной сверки цены, состава и условий заказа.

Перед включением отправки:

1. Утвердите политику в `privacy.html` и текст согласия. Укажите оператора, адрес и контакт для обращений, получателей и места обработки данных, сроки хранения и порядок удаления. Проверьте применимость требований к локализации и трансграничной передаче для фактической схемы работы с Formspree. Снимите `noindex` только если утверждённая политика должна индексироваться.
2. В Formspree создайте форму, настройте и подтвердите адрес получателя заявок, проверьте уведомления и антиспам-настройки. В запросе передаётся поле `email` для Reply-To и поле `subject` для темы письма. Проверьте, что уведомление использует эти поля.
3. В `checkout-config.js` укажите публичный ID формы в `formspreeFormId`. Переключите `orderSubmissionEnabled` на `true` только после проверки допустимости обработки. Секреты здесь не нужны.
4. На тестовой форме проверьте приём заявки с опубликованного домена, затем согласуйте проверку получения письма на рабочем адресе. Сверьте тему, Reply-To, контакты, доставку, состав, суммы и время. При успешном ответе сервиса сайт сообщает о приёме заявки и очищает корзину. При сбое форма и корзина сохраняются в текущей вкладке.
