# Ётун — сайт бренда

Статический адаптивный сайт на HTML, CSS и обычном JavaScript. Для локального запуска нужен только Python 3. Google Fonts и Яндекс Метрика загружаются при наличии доступа к их сервисам.

## Локальный просмотр

Из папки, где находится `index.html`:

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000/. Проверьте логотип, четыре карточки каталога и переходы к разделам «Изделия», «Материал» и «О бренде». Favicon доступен по адресу http://localhost:8000/favicon.svg.

## Публикация

Загрузите содержимое этой папки в корень публичного репозитория GitHub и включите GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Изображения

### Готовы к публикации

- `assets/etun-logo.png` — логотип с прозрачными углами, который используется на странице и в метаданных Open Graph. В репозитории также есть его WebP-версия.
- `assets/ice-axe.webp`, `assets/ice-tool.webp`, `assets/ice-screw.webp` и `assets/crampons.webp` — фотографии товаров, предоставленные владельцем.
- `favicon.svg` — иконка сайта с прозрачной областью вокруг эмблемы.

### Фотографии для редизайна

В [`assets/editorial/`](assets/editorial/README.md) готовы к публикации пять собственных снимков из архива `etun_website_photos_combined.zip`. Это пейзажи и ледяные фактуры без людей. Кадры №8, 18, 21 и 22 отсутствуют в архиве и не используются. Подготовленные WebP пока не подключены к странице.

Длинная сторона WebP не превышает 1920 px. Файлы записаны с качеством 80 без EXIF и GPS-метаданных. Архив и распакованные собственные исходники хранятся вне репозитория в `/workspace/etun-photo-intake/` и `/workspace/etun-photo-intake/originals/` соответственно.

### Стоковые фотографии

Подготовка пяти стоковых кадров завершена. Оптимизированные WebP находятся в [`assets/editorial/`](assets/editorial/README.md). Авторы, оригиналы и лицензии приведены в [CREDITS.md](assets/editorial/CREDITS.md). Стоковые изображения пока не подключены к странице.

Стоковые исходники и промежуточные копии хранятся вне репозитория в `/workspace/etun-photo-intake/pending-license/`.
